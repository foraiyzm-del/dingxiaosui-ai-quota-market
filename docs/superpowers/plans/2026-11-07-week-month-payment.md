# 周卡与月卡付款实施记录

目标：在独立商城现有尝鲜卡流程中新增周卡 29.90 元（30/45/6）、月卡 99 元（100/150/20），每次核销交付一张卡。用户已明确要求开放；旺季卡、自由组合仍为展示。

方案：沿用稳定购买账户和权益兑换事务，服务端将三档固定卡分别绑定专用收款项目。当前官方 COUNT 核销固定 1 次且权益在项目内共用，因此不使用旧 nsy 多套餐项目发不同卡；独立项目是避免跨价位兑换的选择。原尝鲜卡配置与旧记录兼容。实际只读核对确认三档专用配置均有效，周/月在用户保存 Key 后已启用；真实扫码验收待用户操作。

不提交、推送或部署；不调用收费模型，不代用户付款，不修改原商户套餐。不将配置或模拟验收写成真实周/月付款通过。

- [x] 核销协调器按固定 packageId 绑定独立配置、快照与恢复；先补跨包、并发、重启和激活测试再实现。
- [x] 商城与购买页显示所选套餐，历史意图始终以持久快照为准；测试篡改参数、未配置不开放支付。
- [x] 私密配置初始化与只读探针支持三档；周/月占位不覆盖原 Key。导出新增独立模拟启动器。
- [x] 隔离模拟依次完成周/月购买、单次核销、单卡交付和准确激活；浏览器检查实际页面。
- [x] 完成自动化回归、私有数据备份和哈希审计，同步独立商城；仅经匹配探针的配置可开放真实购买。
- [x] 协助创建两个专用项目，用户完成支付宝套餐配置并私密保存 Key；只读探针确认各自单 SKU、正确价格与 COUNT 1，启用配置并重启本机 3399，浏览器检查两档付款入口。
- [ ] 周/月真实扫码付款验收：需用户亲自付款；当前仅配置与模拟通过，没有新增真实付款或核销。
