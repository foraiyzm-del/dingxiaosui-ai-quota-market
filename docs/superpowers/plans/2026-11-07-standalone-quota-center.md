# 独立多项目额度中心实施记录

**Goal:** 将现有额度集市导出为无需丁小穗源码的独立平台，统一购买、项目独立账户、项目独立分项计次。

**Architecture:** 复用 Node HTTP/SQLite 中心与服务端 SDK；独立导出只复制许可清单内源码。丁小穗是已有接入方，一二大模型为待接入方；先用第二项目模拟证明隔离，不伪造真实应用接入。

**Tech Stack:** Node.js 24+、npm 原锁文件、SQLite、原生浏览器页面。

**Spec:** [standalone-integration.md](../../standalone-integration.md)

## 约束与验证重点

- 不推送、部署、复制生产数据或运行真实模型。
- 保留已有 manual/epay 和丁小穗单套餐 OPC；不将上游不同兑换规则混入一个权益池。
- 用户选择统一商城购买、各项目保留账户。实际一二大模型源码地址待提供。
- 未知项目链接不得静默选购别的项目；卡、余额、任务按项目隔离。
- 非丁小穗导出不能沿用丁小穗二维码域名；公开门户不能借“拒收”退回已经生成的额度。
- 独立包安装、语法检查、纯中心全套测试及真实页面演示都要实际运行。
