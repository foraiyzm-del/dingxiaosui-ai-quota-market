## 已修复的验收发现

1. 官方 `alipays://platformapi/startapp` 深链此前被 HTTPS-only 校验挡住：增加精确协议白名单和测试。
2. 同项目 Key 轮换阻挡未知核销恢复：允许只查原消费；新 Key 查不到时禁止重新扣减。
3. 停止新增购买误伤已有权益：新购买要求 ENABLED，已有权益继续按 access 判断。
4. 退出仅清 Cookie：补服务端撤销及 365 天失效。
5. 模拟页面 `no-referrer` 使表单 Origin 为 null：改为 same-origin，仍拒绝 null 来源。
6. 演示直接运行 standalone 缺静态工作台：创建私有完整运行快照，并把工作台 HTTP 200 加入启动验收。
7. 窄屏长编号溢出、记录切换后按钮未恢复：已修正并浏览器复验。

基线无业务测试失败；开发中未完成模块导入导致的暂时失败在文件完成后消失，不属于原项目问题。
